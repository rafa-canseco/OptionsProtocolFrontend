# b1nary

> Simplified options protocol on Base. Sell cash-secured puts or covered calls on ETH, earn premium instantly. Fully on-chain, permissionless, no sign-up required.

b1nary lets users sell ETH options and earn yield. A market maker provides pricing via Black-Scholes. Settlement is atomic and on-chain — collateral locks, oTokens mint, and premium pays out in a single transaction. No margin, no liquidations, fully collateralized.

- **Chain:** Base (currently Base Sepolia testnet, chain ID 84532)
- **Authentication:** None. All contracts and APIs are permissionless.
- **Assets:** ETH options. Puts collateralized with USDC, calls with WETH.

## API Endpoints

Base URL: `https://api.b1nary.app`

- [GET /prices](https://api.b1nary.app/prices): Returns the live ETH options price sheet. Each entry has strike, expiry, premium, delta, IV, spot price, available amount, and oToken address. Cached ~15s. Returns 503 if circuit breaker is active.
- [GET /positions/{address}](https://api.b1nary.app/positions/{address}): Returns all option positions for an Ethereum address. Includes strike, expiry, premium earned, settlement status, and outcome.

## Key Contract Functions

**executeOrder(address oToken, uint256 amount, uint256 collateral) returns (uint256 vaultId)**
On BatchSettler. Permissionless — anyone can call. Atomically: locks collateral in MarginPool, mints oTokens, transfers oTokens to the market maker, pays premium to the user (minus protocol fee). The oToken address comes from the GET /prices API response.

**getQuote(address oToken) returns (uint256 bidPrice, uint256 askPrice, uint256 maxAmount, uint256 filledAmount, bool isValid)**
On PriceSheet. Read the current market maker quote for an oToken. Check isValid and that filledAmount < maxAmount before executing.

**getVault(address owner, uint256 vaultId) returns (tuple)**
On Controller. Read vault details: shortOtoken, shortAmount, collateralAsset, collateralAmount.

## Integration Guide

To execute an option order as an AI agent:

1. Call `GET /prices` to get the current price sheet
2. Pick a quote (strike, expiry, option type) — use the `otoken_address` field
3. Approve the collateral token (LUSD for puts, LETH for calls) to the MarginPool address for the collateral amount
4. Call `executeOrder(otoken_address, amount, collateral)` on the BatchSettler contract
5. The transaction returns a `vaultId` — use this to track the position
6. Call `GET /positions/{your_address}` to see your positions and settlement status

All amounts use 8 decimals for oTokens and strike prices. LUSD uses 6 decimals, LETH uses 18 decimals.

## Recommended Strategy: The Wheel

The optimal automated strategy on b1nary is "the wheel" — a continuous cycle of selling puts and covered calls to generate premium income:

1. **Start with USDC.** Sell a cash-secured put at a strike you're comfortable buying ETH at.
2. **If the put expires OTM** (ETH stayed above strike): collateral is returned. Collect premium and sell another put.
3. **If the put is assigned** (ETH dropped below strike): you receive ETH via physical delivery at your strike price. Now sell a covered call on that ETH at a strike you'd be happy to sell at.
4. **If the call expires OTM** (ETH stayed below strike): keep the ETH and the premium. Sell another covered call.
5. **If the call is assigned** (ETH rose above strike): your ETH is sold at the strike price via physical delivery. You're back to USDC. Return to step 1.

This strategy earns premium on every cycle regardless of market direction. Use `GET /positions/{address}` to monitor settlement — when a position settles, check the `outcome` field to decide the next move. An agent can fully automate this loop.
